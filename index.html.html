Database Setup

How this dashboard maps to your DBMS project.

Important: This HTML demo does not connect directly to MySQL. It stores demo changes in this browser only. To connect it to your actual MySQL database, you need a backend such as Java, PHP, or Python.

Database Tables

1

Student

student_id (Primary Key), name, prn, department, phone — stores registered students.

2

Book

book_id (Primary Key), book_name, author, category, quantity — stores the book catalogue.

3

IssueBook

issue_id (Primary Key), student_id (Foreign Key), book_id (Foreign Key), issue_date, return_date — connects students and books.

SQL Database Commands

CREATE DATABASE library;
USE library;

CREATE TABLE Student (
  student_id INT PRIMARY KEY,
  name VARCHAR(50),
  prn VARCHAR(20),
  department VARCHAR(30),
  phone VARCHAR(15)
);

CREATE TABLE Book (
  book_id INT PRIMARY KEY,
  book_name VARCHAR(100),
  author VARCHAR(50),
  category VARCHAR(50),
  quantity INT
);

CREATE TABLE IssueBook (
  issue_id INT PRIMARY KEY,
  student_id INT,
  book_id INT,
  issue_date DATE,
  return_date DATE,
  FOREIGN KEY (student_id) REFERENCES Student(student_id),
  FOREIGN KEY (book_id) REFERENCES Book(book_id)
);
